# Repository contents and exclusions

Committed files contain source notebooks, PDFs, audit scripts, reviewer tables, OOF predictions, metrics, fold assignments, baseline registry and literature metadata.

Ignored files contain Kaggle raw downloads, private model/input archives, virtual environments, large feature caches, fold model checkpoints and temporary logs. They are reproducible or downloadable from the recorded manifests and should not be committed to a public or private Git repository.

No Kaggle token, GitHub token or other credential is part of this repository.
